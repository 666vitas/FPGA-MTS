# AI + FPGA 项目协作流程

## 0. 本文件作用

本文件规定本项目中用户、Codex、GPT、Claude Code 的分工方式。项目总目标是：

```text
基于 Red Pitaya 的全自动数字稳频参数优化系统
```

核心架构不是“AI 直接控制一切”，而是：

```text
FPGA = 快速、确定、实时的内环
AI   = 慢速、监督、调参、识别和重锁的外环
```

## 1. 四个角色

### 1.1 用户

用户负责真实实验动作：

- 接线；
- 开关设备；
- 调信号源；
- 观察示波器；
- 保存截图和 CSV；
- 记录实验现象；
- 把现象反馈给 GPT / Codex。

用户当前不需要写 FPGA 代码，也不需要手动改 Verilog。

### 1.2 Codex

Codex 负责本地工程执行：

- 读取代码和文档；
- 修改 RTL；
- 写 testbench；
- 写实验 SOP；
- 更新版本记录；
- 生成报告；
- 汇总 diff 和风险；
- 不跨阶段开发。

Codex 不负责擅自上板、不负责擅自运行 Vivado、不负责把未验证方案直接推进到闭环。

### 1.3 GPT

GPT 负责实验现象和方案审查：

- 判断示波器现象是否符合物理预期；
- 判断下一步是否安全；
- 审查 Codex 的开发计划；
- 帮用户生成更清楚的 Codex 指令；
- 在“是否进入下一阶段”上给出保守判断。

### 1.4 Claude Code

Claude Code 负责代码第二审查：

- signed / unsigned；
- 位宽；
- overflow；
- saturation；
- reset；
- enable；
- mode 保留；
- testbench 覆盖；
- Vivado 风险；
- 是否误改官方底层。

Claude Code 的角色是给 Codex 代码做工程复核，不替代真实实验。

## 2. 固定工作循环

推荐每一轮按下面循环推进：

```text
用户实验结果
  -> GPT 判断现象和下一步
  -> Codex 更新文档 / SOP / 必要代码
  -> GPT 审查方案
  -> Claude Code 校验代码
  -> 用户测试
  -> 回到实验结果
```

不要跳过中间环节。尤其不要在没有实验依赖性验证时直接进入 PID 或 AI。

## 3. FPGA 与 AI 分工

### 3.1 FPGA 快速内环

FPGA 负责：

- ADC 采样；
- digital mixer；
- post-mixer LPF；
- output protection；
- 后续 PID；
- 后续状态机；
- 必要的安全限幅。

这些任务要求确定性、低延迟、可解释，不适合让大模型或外部 PC 直接插入最快环路。

### 3.2 AI 慢速外环

AI 负责：

- 锁定状态识别；
- 目标峰识别；
- 参数推荐；
- REF phase / LPF / gain 建议；
- 自动重锁策略；
- 跨工况判断；
- benchmark 分析。

AI 不直接替代 FPGA mixer、LPF 或快速 PID。AI 的输入应来自实验数据、示波器 CSV、锁定状态日志和慢速特征。

## 4. 当前阶段的协作方式

当前阶段是：

```text
v1i_D2-125 安全接入前置验证
```

用户要做的是测试：

- FPGA OUT1 是否安全输入 D2-125；
- D2-125 后级输出是否稳定；
- IN1 / IN2 / OUT1 依赖性是否成立；
- 是否存在削顶、offset、极性、噪声问题。

Codex 要做的是：

- 生成 SOP；
- 更新路线图；
- 不写 PID；
- 不写 AI；
- 不盲目增加 digital gain。

GPT 要做的是：

- 看示波器现象；
- 判断是否允许低增益短时间闭环；
- 判断是否需要 v1g gain 或 v1h phase。

Claude Code 暂时只在需要改 RTL 时介入。

## 5. 后续版本中的 AI 位置

| 阶段 | AI 是否参与 | 说明 |
|---|---|---|
| v1 | 不参与实时控制 | 只做数据记录和路线审查 |
| v2 | 不直接参与 PID 内环 | FPGA PID 先跑通 |
| v3 | 可辅助设计 FSM | 但 FSM 本身是确定性自动化 |
| v4 | 重点参与数据集和 benchmark | 采集锁定 / 失锁 / 误锁 / 重锁数据 |
| v5 | 正式参与 | 做锁态识别、参数推荐、自动重锁策略 |

## 6. 每次任务的最小输出

每次 Codex / GPT 任务结束必须回答：

1. 当前阶段；
2. 本次是否修改代码；
3. 本次是否修改文档；
4. 是否运行 Vivado；
5. 是否允许上板；
6. 是否允许接 D2-125；
7. 是否允许闭环；
8. 是否允许 PID / AI；
9. 下一步用户需要做什么。

当前默认答案是：

```text
不允许直接闭环。
不允许 PID。
不允许 AI。
```
