# 中文交接模板

每次按以下顺序输出，证据不足处明确写“未验证”或“等待验证”：

**A. 本次目标**

**B. 实际读取的文件与 branch/HEAD**

**C. 修改前判断**

**D. 修改文件**

**E. 每个文件的变化**

**F. 未修改边界**

**G. 已执行验证**

**H. 验证结果**

**I. 未执行验证**

**J. 当前证据等级**

**K. 剩余风险**

**L. 用户下一步实验步骤**

**M. PASS 判据**

**N. FAIL 判据**

**O. 必须 SAFE 条件**

**P. 下一步唯一任务**

**Q. 建议 commit message**（仅建议；未经用户明确要求不 commit）
