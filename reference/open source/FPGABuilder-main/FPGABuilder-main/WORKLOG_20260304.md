# 工程工作记录 - 2026年3月4日

## 任务
实现Vivado插件的program命令烧录逻辑，完整支持FPGABuilder vivado program --help中的功能，并且适配FPGABuilder program命令。

## 更改概述

### 1. 修改的文件

1. `src/plugins/vivado/tcl_templates.py`
   - 添加`ProgramDeviceTemplate`类，支持JTAG和Flash编程模板
   - 在`TCLScriptGenerator`类中添加`generate_program_device_script()`方法
   - JTAG编程模板：连接硬件服务器、打开硬件目标、编程FPGA
   - Flash编程模板：查找MCS文件、创建硬件配置存储器、编程Flash

2. `src/plugins/vivado/plugin.py`
   - 重写`program_device()`方法，实现完整的编程流程
   - Flash模式下自动调用`generate_mcs_file()`生成MCS文件
   - 使用`TCLScriptGenerator`生成编程脚本并执行
   - 添加编程结果工件信息

### 2. 实现的功能

1. **JTAG编程**
   - 支持电缆类型参数（--cable）
   - 支持硬件服务器地址参数（--target）
   - 支持比特流文件参数（--bitfile），可自动查找
   - 完整的硬件连接、编程、验证、断开流程

2. **Flash编程**
   - 支持--flash标志
   - 自动生成MCS文件（通过现有`generate_mcs_file()`方法）
   - 查找MCS文件并编程到Flash
   - 支持擦除、空白检查、验证选项

3. **配置集成**
   - 从项目配置的`programming`部分读取参数
   - 支持命令行参数覆盖配置
   - 编程结果包含详细的工件和日志信息

### 3. 命令行接口

1. **顶层program命令** (`run.py program`)
   ```bash
   run.py program --cable xilinx_tcf --target hw_server:3121 --bitfile path/to/bitfile.bit
   ```

2. **Vivado program命令** (`run.py vivado program`)
   ```bash
   run.py vivado program --cable xilinx_tcf --target hw_server:3121 --bitfile path/to/bitfile.bit --flash
   ```

3. 电缆类型需要与硬件匹配
4. 需要Vivado工具链已安装并检测到
