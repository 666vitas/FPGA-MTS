# 建议实施优先级与禁止事项

> 限制：总项数 8，基础 P-only 前不扩展 PI/relock/AI/双执行器自动控制。

## 优先级

| # | 优先级 | 项目 | 为什么 | 完成判据 |
|---:|---|---|---|---|
| 1 | P0 | 完成现有 XDC/check_timing 逐项审计 | 当前 routed setup/hold 已过，但完整 Timing Gate 未过 | unconstrained paths=0；每个 no-clock/no-delay 有真实接口解释，不用 blanket false path |
| 2 | P0 | 记录 D2-125 external-controller 人工确认 | 当前代码完全未建模 current loop，真实 plant 未知 | Error Input、Servo Output connection、ON/OFF/HOLD、polarity、integrator、bandwidth 均有用户记录 |
| 3 | P0 | 纠正 GUI/流程中 D2 接线歧义 | 当前文案可被误读为 D2 Error Input 已接 FPGA OUT1 | UI 明确 `USER CONFIRMED/UNKNOWN`，不伪装自动检测 |
| 4 | P1 | 建立统一 `scan_generation` target freshness | 当前只有 capture/config generation，scan 参数改变的失效契约不完整 | scan start/parameter change 递增；target绑定 capture+scan+config generations |
| 5 | P1 | 强制 VALIDATE→operator compare→ACTIVE | L1 已有 VALIDATE，但流程需要强制使用 | event generation/directions/OUT2/error coherent 才解锁 ACTIVE |
| 6 | P1 | 执行一次用户批准的 Kp=0 hardware Gate | 数字 RTL 不能证明 loaded PZT bumpless | actual OUT2、scope node、谱峰、D2 state、final SAFE 全部记录 |
| 7 | P1 | 用户批准后执行最小非零 P-only Gate | 证明真实 effective plant 为负反馈 | error 改善、无 saturation/limit drift、谱峰无明显偏移、持续时间达标 |
| 8 | P2 | H4 后评估 Linien line identity | 只在 jitter/相邻谱线误识别成为真实问题时有价值 | 独立 Gate 比较 simple correlation，不改 realtime P-only datapath |

## 不建议引入

- **Linien robust autolock**：当前过度复杂，且外部 D2 ownership 假设不成立。
- **Linien/PyRPL slow integrator 或 multi-actuator 自动协调**：在 D2 current
  loop 状态未知时属于 `DANGEROUS UNDER CURRENT HYBRID LOOP`。
- **PyRPL installer 作为产品依赖**：未签名、非源码、commit/license 无法
  从本地包完整核验，且绑定自己的 FPGA image/CSR。
- **redpid relock sweep**：当前禁止自动重锁，扩展 sweep 可能与 D2 打架。
- **official PID 替换当前 P-only controller**：不解决 acquisition 或 hybrid
  plant，且会引入 Ki/D state 与新 timing。
- **FPGABuilder 迁移**：alpha、重复实现/placeholder、非商业 license，改变
  已有 build evidence，不服务首个 P-only。
- **大规模 GUI/server 重写**：先用 adapter 完成真实 Gate。
- **AI/ML/IQ/PSD/PI**：全部是 H4 后的独立 Gate。

## 不得自行假设

- D2-125 是快环或慢环；
- D2-125 是否含积分、是否 reset、是否 enable；
- OUT1 已连接 D2 Error Input；
- current 与 PZT polarity/bandwidth 已分离；
- FPGA `P_LOCKED` 等于频率长期稳定；
- 数字 0/1-count jump 等于 loaded PZT 模拟无跳变；
- 任何开源 default parameter 适合真实混合系统。

## 推荐唯一下一步

保持当前产品代码和硬件不动，先按 `version/STATUS.md` 对现有 XDC 与
`check_timing` 项逐项完成只读语义审计；与此同时由用户准备 D2-125
五项状态确认数据。完整 Timing Gate 与 D2 状态均明确后，才制定一次
`ARM VALIDATE` 硬件实验。
