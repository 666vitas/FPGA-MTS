# 实验信号检查清单

## 0. 本文件作用

本文件用于每次接线前检查信号是否安全。

FPGA 新手最容易犯的错不是代码，而是把过大的模拟信号直接接进板子。

## 1. 我需要理解什么

Red Pitaya 的输入不是无限耐压。

因此，进入 `IN1/IN2` 前必须先确认：

- 频率；
- 幅度；
- offset；
- 是否经过衰减；
- 是否超过输入范围。

## 2. 我需要操作什么

每次接线前填表：

| 信号 | 接到哪里 | 频率 | Vpp | offset | 是否安全 |
|---|---|---|---|---|---|
| PD | `IN1` | 待测 | 待测 | 待测 | 待确认 |
| REF | `IN2` | `4.6 MHz` | 必须安全衰减 | `0 V` 优先 | 待确认 |
| OUT1 | 示波器 | 输出 | 待测 | 待测 | 先不接 D2-125 |
| EOM drive | EOM | `4.6 MHz` | 约 `8.93 Vpp` | 待确认 | 不进 Red Pitaya |

## 3. 我需要发给 GPT 什么

发给 GPT：

```text
1. PD 信号 Vpp 和 offset
2. REF 信号 Vpp 和 offset
3. EOM drive 是否和 REF 分开
4. 示波器截图
5. Red Pitaya 输入量程设置
```

## 4. Codex 应该生成什么

Codex 应根据这些参数更新：

- board test 文档；
- filter 参数计划；
- gain/limit 参数；
- 风险说明。

## 5. 成功标准是什么

接线前成功标准：

- `IN1` 不超范围；
- `IN2` 不超范围；
- `REF` 已衰减；
- `6.32 Vpp` REF 没有直接接 `IN2`；
- `OUT1` 先接示波器；
- 没有接激光器反馈。

## 6. 失败怎么排查

| 问题 | 处理 |
|---|---|
| 不知道 Vpp | 先用示波器量 |
| 不知道 offset | 示波器 DC coupling 量 |
| REF 太大 | 加衰减器或降低信号源输出 |
| PD 太大 | 加衰减或检查前级增益 |
| 不确定输入量程 | 查 Red Pitaya 板卡配置，问 GPT 审查 |

## 7. 我现在只需要记住什么

上板前最重要的不是代码，是这句话：

```text
任何进 IN1/IN2 的信号，先用示波器确认安全。
```
